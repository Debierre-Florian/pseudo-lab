Structure


action mon_programme
const var N = 10
type vecteur = tableau[1..N] de type entier
var i, total : entier
var T : vecteur

debut
  ...instructions...
fin

        
Types : entier, reel, booleen, caractere, chaine.

      

      

        
Entrées / sorties


sortir("Total : ", total)
entrer(x)
entrer(a, b, c)
retour a la ligne

        
sortir ne passe pas à la ligne tout seul (comme dans les TD) : utilise retour a la ligne ou "\n", ou coche l'option au-dessus de la console.

Tableaux et matrices


T[1] <- 5
sortir(T[i])
M[i][j] <- 0     // ou M[i, j]

        
Les bornes sont vérifiées : écrire T[0] ou T[N+1] sur un tableau [1..N] donne une erreur avec le numéro de ligne.

      

      

        
Fonctions et procédures


action principal

fonction carre(x : entier) : entier
var y : entier          // variables locales
debut
  y <- x * x
  retourner(y)
fin

procedure echanger(var a : entier, var b : entier)
var t : entier
debut
  t <- a
  a <- b
  b <- t
fin

var u, v : entier
debut
  u <- carre(5)
  v <- 1
  echanger(u, v)    // appel : juste le nom
fin

        
Les sous-programmes s'écrivent avant le debut du programme principal. Une fonction retourne un résultat avec retourner(...) ; une procédure ne retourne rien.

        
Paramètres : sans mot-clé = par valeur (copie, l'appelant ne change pas) ; avec var = par variable (l'appelant est modifié, il faut donner une variable). On peut séparer les paramètres par , ou ; et grouper a, b : entier.

        
Une variable locale masque une variable globale de même nom. La récursivité marche (200 appels imbriqués au maximum). Un tableau en paramètre se déclare avec un type : tab : vecteur.

Messages du site

        
✗ Erreur : le programme s'arrête, la ligne fautive est surlignée.

        
⚠ Avertissement : le programme continue mais quelque chose cloche (variable non déclarée, non initialisée, nombre à virgule rangé dans un entier…). Active le mode strict pour en faire des erreurs.
